# Datos

Acá va **`catalogo.json`**: todos los productos, talles, precios y colores, en un formato que la web puede leer.

Todo lo que está en `public/` se publica tal cual, con una dirección fija (ej.: `tusitio.com/data/catalogo.json`). En la etapa 2, estos datos van a venir del servidor (NestJS) y este archivo se va a reemplazar.
