# Catálogo

Todo lo que muestra productos: el **listado por categoría** (Pretales, Collares, Correas, Kits, Paseadores, Identificadores, Decoración, Accesorios) y la **ficha de cada producto** (fotos, descripción, talles, precio).

Acá también va el código que **pide los datos de `public/data/catalogo.json`** con Axios y TanStack Query (el mozo y el mozo con memoria).
